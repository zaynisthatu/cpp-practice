# C++ Practice Exercises

35 console programs in C++, written between February 2022 and July 2023: basic input/output and arithmetic, conditionals, unit conversions, classes, inheritance, polymorphism, exception handling and a menu-driven bank program.

The source files are in `exercises/`. Every program has a note next to it, `<name>.cpp.README.md`, with a description of what it does and the file's original name.

## Build and run

```
cd exercises
g++ <name>.cpp -o <name>
./<name>
```
