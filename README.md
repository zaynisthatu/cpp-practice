# C++ Practice Exercises

35 console programs in C++, written between February 2022 and July 2023. They progress from basic input/output and arithmetic, through conditionals and unit conversions, to classes, inheritance, polymorphism, exception handling and a menu-driven bank program.

## Contents

The source files are in `exercises/`. Every program has a note next to it, `<name>.cpp.README.md`, describing what it does and the file's original name.

| Area | Programs |
|---|---|
| Input and arithmetic | `sum_of_two_numbers`, `sum_of_two_numbers_v2`, `swap_two_numbers`, `simple_interest_calculator`, `area`, `gross_salary_calculator`, `salary_bonus_calculator`, `phone_bill_calculator`, `marks_average_calculator` |
| Conditionals | `compare_two_numbers`, `even_or_odd`, `leap_year_checker`, `minimum_of_three`, `youngest_of_three`, `youngest_of_three_duplicate`, `triangle_angle_sum_check` |
| Unit conversions | `celsius_to_fahrenheit_buggy`, `fahrenheit_to_celsius`, `fahrenheit_to_celsius_v2`, `feet_to_inches_converter`, `days_to_years_weeks_months`, `seconds_to_hms_converter` |
| Quadratic equation | `quadratic_equation_input`, `quadratic_equation_v2` |
| Classes, inheritance, polymorphism | `marks_class_exercise`, `minimal_class_example`, `book_record_class`, `counter_inheritance_exercise`, `poly` |
| Exception handling | `exception_handling_practice` |
| Menu-driven programs | `bank_menu_practice`, `bank_menu_draft` |
| Sketches and placeholders | `marks_table_sketch_BROKEN`, `vowel_check_BROKEN` (unfinished, do not compile), `placeholder_name_print` |

## Build and run

```
cd exercises
g++ <name>.cpp -o <name>
./<name>
```
